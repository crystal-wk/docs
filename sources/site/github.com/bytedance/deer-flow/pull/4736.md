## Pull request overview

This PR fixes a developer-diagnostics path resolution bug where `scripts/check.py` and `scripts/doctor.py` could compute `scripts/pnpm.py` and `frontend/` relative to the invocation path / current working directory, causing `make check` / `make dev` flows to fail when the scripts are invoked via relative paths.

**Changes:**

- Resolve `scripts/pnpm.py` via `Path(__file__).resolve()` in `scripts/check.py` and `scripts/doctor.py` so derived paths are absolute and stable.
- Add regression tests that load the scripts via relative paths and assert `PNPM_SCRIPT_PATH` and `FRONTEND_DIR` are absolute and correct.
- Document the caller-independent behavior in `README.md` and `AGENTS.md`.
