## Summary

- Accept the six documented E2B reconciliation settings.
- Add regression coverage for valid documented settings.
- Keep warnings for truly unknown sandbox fields.

## Root cause

The provider reads reconciliation settings from Pydantic extra fields. Its allowlist omitted those supported fields.

## Impact

Valid E2B configuration no longer produces misleading startup warnings. Reconciliation behavior and defaults do not change.
