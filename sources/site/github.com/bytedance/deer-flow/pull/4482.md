Fixes [#4481](https://github.com/bytedance/deer-flow/issues/4481)

## Why

The documented default backend `make test` command currently includes 
`tests/test_client_live.py`. That module skips only in CI or when the repository-root 
`config.yaml` is absent, so a normally configured local checkout can unintentionally 
run 19 real `DeerFlowClient` integration tests.

Those tests can contact configured LLM providers, incur charges, fail nondeterministically, 
and modify live test resources. Although the module docstring says they must be run 
explicitly, the test policy did not enforce that requirement.

## What changed

- The default backend test target now excludes tests marked `live`.
- A dedicated `make test-live` target requires an explicit 
 `DEER_FLOW_RUN_LIVE_TESTS=1` opt-in.
- Live client tests are marked consistently, always skip in CI, and skip unless both 
 the opt-in and a root `config.yaml` are present.
- Subprocess-based policy tests cover default collection, explicit opt-in, CI, and 
 missing-config behavior without executing live test bodies.
- Contributor and backend documentation now distinguishes safe default tests from 
 explicitly opted-in live tests.

## Bug fix verification

- Test path that reproduces the bug: `backend/tests/test_client_live_policy.py`
- Did it go red on `main` and green on this branch? **Yes.** On `main`, live client 
 tests are collected whenever `config.yaml` exists and `CI` is unset. On this branch, 
 the policy test confirms collection requires the explicit opt-in while CI remains 
 unconditionally safe.

- Full backend suite with live tests excluded: `9613 passed, 29 skipped`; two unrelated 
 timing-sensitive lease tests failed during the loaded run, then passed when rerun in

- `ruff check .`: passed.
- `ruff format --check .`: 979 files already formatted.
- `git diff --check upstream/main...HEAD`: clean.
- `make -n test` and `make -n test-live`: commands select the intended safe/default and 
 explicit-live paths.

No live test body was executed and no real `config.yaml` contents were read.
