## Summary

- add an admin-only local `.skill` upload/install action to Settings > Skills
- stream multipart uploads into randomized temporary files with a 20 MiB compressed-size limit and guaranteed cleanup
- reuse the existing user-scoped installer, safe ZIP extraction, SkillScan checks, duplicate protection, error mapping, and prompt-cache refresh
- add pending/admin/success/error UI states plus English and Chinese translations

## Motivation

The existing install endpoint resolves a `.skill` archive from a thread artifact path. Administrators who already have a local archive must first create a chat thread and place the artifact there. This adds a direct settings workflow without changing the established installation security boundary.

## Scope

This PR intentionally does not add Git repository installation, registry discovery, overwrite behavior, archive preview, or upload progress percentages.

- `uv run pytest tests/blocking_io/test_skills_upload_router.py tests/blocking_io/test_skills_install.py -q`

- `uv run ruff format --check .`
- `python ../scripts/pnpm.py test`
- `python ../scripts/pnpm.py check`
- manual settings-page upload with a valid text-only `.skill` archive
