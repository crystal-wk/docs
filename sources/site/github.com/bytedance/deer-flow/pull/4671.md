# PR [#2](https://github.com/bytedance/deer-flow/pull/2) 正文（fix/memory-config-redaction）— 按上游模板改写，中文

## Why

`GET /api/memory/config` 会把 `backend_config` 原样返回给**任何已认证用户**，其中包括宿主机的 `storage_path`（全实例所有用户记忆数据的存放根目录）。而 `integrations.py` 已经对非 admin 调用者脱敏主机路径——memory 是唯一的例外，与项目自身的安全惯例不一致。

威胁模型边界：

- 单用户本地部署（默认形态）：信息级问题，机器主人本就知晓路径
- 多用户部署（自注册默认开放、IM 通道按用户绑定）：任意低权限用户可获知全局存储布局，为路径遍历/沙箱定向攻击提供侦察情报

## What changed

- 复用 `integrations.py` 的 fail-closed `_is_admin_user` 模式（任何鉴权异常均按非 admin 处理）
- 非 admin 调用者响应中 `storage_path` 置为 `null`，其余 `backend_config` 字段不变；admin 不受影响
- 行为变化：非 admin 用户看到的 `storage_path` 由真实路径变为 `null`

## Surface area

- [ ] **Frontend UI**
- [x] **Backend API** — `GET /api/memory/config` 响应体
- [ ] **Agents / LangGraph**
- [ ] **Sandbox**
- [ ] **Skills**
- [ ] **Dependencies**
- [ ] **Default behavior change** — 非 admin 调用者响应中 `storage_path` 脱敏
- [ ] **Docs / tests / CI only**

This redaction is bypassable: `get_memory_status` (line 514) is also non-gated and returns `backend_config=config.backend_config` raw (line 531), so a non-admin caller can simply hit `GET /api/memory/status` and read `storage_path` in the clear — the exact leak this PR intends to close.

The inline comment here says it "Mirrors the redaction in integrations.py," but `integrations.py` applies `include_host_paths=await _is_admin_user(request)` to **every** host-path-emitting route (`status` L245, `config_complete` L301, `auth_complete` L345), not just one. To genuinely mirror that pattern here, factor the redaction into a tiny helper (e.g. `_redact_backend_config(config, request) -> dict`) and call it from both `get_memory_config_endpoint` and `get_memory_status`, then add a non-admin assertion against `/api/memory/status` in `test_memory_router.py`.

(Also worth noting: `get_memory_status` sets `response_model_exclude_none=True`, so once redaction is applied there the `storage_path: None` entry will be stripped from the JSON rather than serialized as `null` — consistent enough, but slightly different from this endpoint's behavior.)
