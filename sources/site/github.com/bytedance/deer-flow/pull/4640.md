## Why

Add SambaNova as a model provider for deer-flow, expanding the supported options for users.

## Root cause

SambaNova provides OpenAI-compatible API access to various models (DeepSeek, Llama, Gemma, etc.) but was not yet supported in deer-flow.

## Fix

- Created `SambaNovaChatModel` provider in `backend/packages/harness/deerflow/models/sambanova_provider.py` following existing patterns (similar to `PatchedChatMiniMax`, `PatchedChatDeepSeek`, etc.)
- Added configuration examples to `config.example.yaml` showing how to configure SambaNova models
- Updated `README.md` with SambaNova setup instructions

The provider subclasses `ChatOpenAI` with the correct base URL (`https://api.sambanova.ai/v1`), leveraging SambaNova's OpenAI-compatible API.

## Tests

- Lint passes: `make lint` in backend/
- YAML configuration is valid (commented examples in config.example.yaml)
- Provider imports correctly and inherits from ChatOpenAI
- API test confirms SambaNova endpoint is OpenAI-compatible and returns correct responses

## Confidence

High. The implementation follows existing patterns, uses the OpenAI-compatible API that SambaNova provides, and lint passes.
