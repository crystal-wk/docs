`[ccf1b69](https://github.com/webfuse-com/deer-flow/commit/ccf1b69f0278657a17a8a2d754255154c6fdbdb8)`

```
The WebGL galaxy on the landing hero (galaxy.jsx, OGL fragment shader) ran
a full-rate rAF loop that never paused, at full device-pixel-ratio, with a
4-layer per-pixel star shader — heavy on weak/software-GL machines and even
in backgrounded tabs.

Adaptive loop (galaxy.jsx):
- Pause the rAF loop while the tab is hidden (visibilitychange); previously
  it rendered at full rate in the background.
- Honor prefers-reduced-motion: render one static frame, never loop.
- Cap to ~30fps (a slow-drifting starfield is indistinguishable from 60).
- Cap backing-store DPR at 1.5 (HiDPI was rendering 2-3x the pixels).
- Skip the per-frame mouse lerp + listeners when mouseRepulsion is off
  (the hero's config), so no wasted work.

Lighter visuals:
- NUM_LAYER 4 -> 3 (~25% less per-pixel shader work).
- hero.tsx: density 0.6 -> 0.45, glowIntensity 0.35 -> 0.25.

Verified: full `pnpm build` (frontend/Dockerfile prod target) green.

Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>
```
