## Why

The backend README was previously available only in English, making the backend architecture, configuration, and development workflow less accessible to Chinese-speaking users and contributors.

This PR adds a Simplified Chinese translation and makes it easy to switch between the English and Chinese versions.

## What changed

- Added `backend/README_zh.md`, a Simplified Chinese translation of the backend README.
- Added language-switch links at the top of `backend/README.md` and `backend/README_zh.md`.
- Preserved commands, API routes, configuration keys, environment variables, links, and code examples from the English README.
- No runtime behavior was changed.
