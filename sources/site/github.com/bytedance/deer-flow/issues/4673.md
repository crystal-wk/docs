### Proposed solution

1. clone excalidraw repository and install dependencies:

```shell
git clone https://github.com/excalidraw/excalidraw-mcp.git
cd excalidraw-mcp-app
pnpm install && pnpm run build
```

2. Launch http mcp server:

```shell
cd dist && node index.js
```

3. Add excalidraw into `extensions_config.json`:

```json
{
  "mcpServers": {
    "excalidraw": {
      "enabled": true,
      "type": "http",
      "url": "http://host.docker.internal:3001/mcp",
      "description": "Excali draw MCP tools for graph plot usage."
    }
  }
}
```

Then naviagte to deerflow webui and try:

> Draw an architecture diagram showing a user connecting to an API server which talks to a database by using excalidraw mcp tool.
