Hi maintainers, thanks for the great work on DeerFlow 2.0!

I noticed that **Milestone 2 (2.1.0)** has no due date set (`due_on: null`), and the Q2 Roadmap ([#1669](https://github.com/bytedance/deer-flow/issues/1669)) doesn't include a timeline either. With ~494/541 milestone issues already closed and v2.0.0 released on 2026-06-25, could you share:

1. Is there an estimated release window for 2.1.0 (e.g., end of August / September)?
2. Among the remaining 47 open issues in milestone 2, are any considered blockers for 2.1.0, or will some slip to 2.2?
3. Will 2.1 ship with a release notes / changelog plan?

No pressure — a rough estimate or "no committed date yet" is totally fine. Thanks!
