## Problem

`E2BSandboxProvider` reports all documented `reconciliation_*` settings as unknown sandbox fields.

`backend/docs/CONFIGURATION.md` documents these settings. The provider also reads and applies them. The warning therefore reports valid configuration as invalid.

## Expected behavior

Documented E2B reconciliation settings do not produce an unknown-field warning. Truly unknown fields still produce the warning.

## Scope

- Add the six documented reconciliation settings to the E2B extra-field allowlist.
- Add a regression test for the documented settings.
- Keep the existing unknown-field warning test.
