Welcome to DeerFlow — an open-source **super-agent harness** built on LangGraph that orchestrates sub-agents, persistent memory, and sandboxed code execution through an extensible skills system. Whether you need deep research, automated coding tasks, or complex multi-step workflows, DeerFlow handles it all through a clean web interface, a terminal workbench, or an embedded Python client.

## What Can DeerFlow Do?

DeerFlow combines a powerful runtime with a rich set of built-in capabilities so you can tackle real-world tasks from day one.

<CardGroup cols={3}>
  <Card title="Multi-Agent Orchestration" icon="network-wired">
    The lead agent delegates to specialist sub-agents on the fly, running them in parallel or sequentially with scoped context and structured result reporting.
  </Card>
  <Card title="Sandboxed Execution" icon="box">
    Run agent-generated code safely in Docker containers, E2B micro-VMs, BoxLite, Kubernetes pods, or directly on your local machine — all configurable from a single YAML file.
  </Card>
  <Card title="Extensible Skills" icon="puzzle-piece">
    Bundle domain knowledge and workflow instructions into `SKILL.md` packages. Activate them on demand with a slash command or let the agent discover them progressively.
  </Card>
  <Card title="Long-Term Memory" icon="brain">
    DeerFlow persists user context and per-agent facts across sessions using the built-in DeerMem engine or a pluggable mem0 backend, with automatic consolidation and staleness review.
  </Card>
  <Card title="MCP Integration" icon="plug">
    Connect any Model Context Protocol server — stdio or HTTP/SSE — to extend the agent's toolset with external APIs, databases, and services without writing custom code.
  </Card>
  <Card title="IM Channels" icon="comments">
    Chat with your agent directly inside Telegram, Slack, Discord, Feishu, DingTalk, WeCom, or WeChat. No public IP or OAuth callback URL required.
  </Card>
</CardGroup>

## Get Up and Running in Three Steps

<Steps>
  <Step title="Install DeerFlow">
    Clone the repository and run the interactive setup wizard to configure your LLM provider, web search, and sandbox preferences.

    ```shell
    git clone https://github.com/bytedance/deer-flow.git
    cd deer-flow
    make setup
    ```
  </Step>
  <Step title="Configure Your Model">
    The setup wizard generates a `config.yaml` with at least one model entry and writes your API keys to `.env`. You can also edit `config.yaml` directly to add additional providers or fine-tune model settings.
  </Step>
  <Step title="Launch">
    Start the full stack with a single command and open the web interface.

    ```shell
    make docker-start   # Docker (recommended)
    # or
    make dev            # local development
    ```

    Then navigate to [http://localhost:2026](http://localhost:2026) and start your first conversation.
  </Step>
</Steps>

<Tip>
  Run `make doctor` at any time to verify your setup and get actionable hints if something is misconfigured.
</Tip>
