Environment variables let you supply secrets and runtime settings to DeerFlow without storing them directly in `config.yaml`. Keeping sensitive values out of your configuration file makes it safer to share configs, check templates into version control, and rotate credentials without editing YAML.

## How to Set Environment Variables

DeerFlow reads environment variables from two places:

1. A `.env` file in the project root (recommended for local development and Docker deployments)
2. Variables exported in your shell before starting the service

Create or edit the `.env` file in your project root:

```shell
# .env
OPENAI_API_KEY=sk-...
TAVILY_API_KEY=tvly-...
```

Reference any environment variable in `config.yaml` with the `$` prefix:

```yaml
models:
  - name: gpt-4o
    api_key: $OPENAI_API_KEY   # DeerFlow substitutes the value at startup
```

DeerFlow substitutes variables at config-load time. If a referenced variable is not set, the field is left empty and DeerFlow logs a warning.

## LLM Provider API Keys

| Variable | Provider |
|---|---|
| `OPENAI_API_KEY` | OpenAI |
| `ANTHROPIC_API_KEY` | Anthropic |
| `DEEPSEEK_API_KEY` | DeepSeek |
| `NOVITA_API_KEY` | Novita (OpenAI-compatible gateway) |
| `MINIMAX_API_KEY` | MiniMax (OpenAI-compatible gateway) |
| `MIMO_API_KEY` | Xiaomi MiMo |
| `CLAUDE_CODE_OAUTH_TOKEN` | Claude Code OAuth token (preferred over file-based auth) |
| `ANTHROPIC_AUTH_TOKEN` | Anthropic alternative auth token |
| `CLAUDE_CODE_OAUTH_TOKEN_FILE_DESCRIPTOR` | File descriptor carrying the Claude Code OAuth token |
| `CLAUDE_CODE_CREDENTIALS_PATH` | Path to a single Claude Code `.credentials.json` file |
| `CODEX_AUTH_PATH` | Path to a Codex CLI `auth.json` file (default: `~/.codex/auth.json`) |

## Runtime Configuration

| Variable | Purpose |
|---|---|
| `DEER_FLOW_CONFIG_PATH` | Absolute path to a custom `config.yaml` file |
| `DEER_FLOW_EXTENSIONS_CONFIG_PATH` | Absolute path to a custom `extensions_config.json` file |
| `DEER_FLOW_HOME` | Runtime state directory (defaults to `.deer-flow` under the project root) |
| `DEER_FLOW_PROJECT_ROOT` | Project root directory for resolving relative runtime paths |
| `DEER_FLOW_SKILLS_PATH` | Skills directory path (overrides `skills.path` in `config.yaml`) |
| `GATEWAY_ENABLE_DOCS` | Set to `false` to disable the Swagger UI (`/docs`), ReDoc (`/redoc`), and OpenAPI schema (`/openapi.json`) endpoints (default: `true`) |

## Example `.env` File

The following is a representative `.env` file covering the most common variables:

```shell
# ── LLM Providers ───────────────────────────────────────────────────────────
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
DEEPSEEK_API_KEY=...

# ── Web Search ───────────────────────────────────────────────────────────────
TAVILY_API_KEY=tvly-...
BRAVE_SEARCH_API_KEY=...

# ── Sandbox ──────────────────────────────────────────────────────────────────
E2B_API_KEY=...

# ── IM Channels ──────────────────────────────────────────────────────────────
TELEGRAM_BOT_TOKEN=...
SLACK_BOT_TOKEN=xoxb-...
SLACK_APP_TOKEN=xapp-...

# ── Observability ────────────────────────────────────────────────────────────
LANGSMITH_TRACING=true
LANGSMITH_API_KEY=ls__...
LANGSMITH_PROJECT=deer-flow

# ── Runtime Paths (override only when needed) ────────────────────────────────
# DEER_FLOW_PROJECT_ROOT=/path/to/deer-flow
# DEER_FLOW_CONFIG_PATH=/path/to/config.yaml
# DEER_FLOW_HOME=/path/to/.deer-flow
```

<Tip>
  Run `make doctor` at any time to verify that all required variables are set and that DeerFlow can reach your configured providers. The command prints actionable fix hints for any missing or misconfigured values.
</Tip>
